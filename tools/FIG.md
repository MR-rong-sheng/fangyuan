# 方圆 · 题图规范（fig）

题库里凡是题干出现「如图 / 图中 / 坐标系中 / 网格中 / 统计图 / 函数图象 / 折叠 / 旋转」的题，
都要配一张图。图**不是**从来源页面抓的位图，而是**按题干条件重画的原创 SVG**：

- 矢量 → 手机上放大不糊，暗色/赛博主题下自动跟着变颜色；
- 零依赖 → 不引外部资源，不引字体；
- 可核对 → 每张图都必须能用题干里给的字母、长度、角度、坐标一一对上（对不上就是画错了）。

## 一、文件与字段

- 文件放 `content/bank/fig/<题目 id>.svg`（id 形如 `cz-2024-14`）。
- 题目对象里加两个字段（都不是必填，但**带图的题必须写 `fig`**）：

```json
{
  "id": "cz-2024-14",
  "fig": "content/bank/fig/cz-2024-14.svg",
  "figAlt": "⊙O 中 AB 为直径，弦 CD 与 AD、BC、BD 相连"
}
```

- 自检/校验器会检查：文件存在、能当 XML 解析、含 `<svg`、**不含 `<script>`**、体积 < 20 KB；
  并统计「题干提到图但缺 fig」的题数（这个数要一路降到 0）。

## 二、画法硬性要求

1. **根元素**：

   ```svg
   <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 360 240" role="img" aria-label="简要描述">
     <title>简要描述</title>
     ...
   </svg>
   ```

   - `viewBox` 按内容定，常用 `0 0 360 240`（横向图形）、`0 0 260 260`（圆、正方形一类）。
   - 四周留 12 单位以上空白，别贴边。
2. **配色一律用 `currentColor`**，不要写死黑/白/具体色值 —— 页面会把文字颜色传进来：

   ```svg
   <g fill="none" stroke="currentColor" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round">
     <circle cx="180" cy="120" r="80"/>
     <path d="M100 120 H260"/>
   </g>
   ```

   - 字母/数字标注：`<text x="…" y="…" fill="currentColor" font-size="13" font-family="ui-sans-serif, system-ui, sans-serif" text-anchor="middle">A</text>`
   - 辅助线（高、中线、延长线、坐标轴虚线）：`stroke-dasharray="4 3"`，并从 `stroke-width="1.2"` 起。
   - 相等的边打等长刻线，直角打小方块 — 都要画，这是题图的信息量所在：

   ```svg
   <!-- 直角小方块（示例：落在角点 P，朝向由两条边决定） -->
   <path d="M0 0 h10 v10" transform="translate(Px,Py) rotate(角度)" fill="none" stroke="currentColor"/>
   ```

3. **几何必须自洽**：坐标要按题干给的数算出来，不要「看着像」。例如
   「矩形 ABCD 中 AD=8、AB=16，BD 的垂直平分线交 AB 于 E、BE=10」
   → 用 10 px/单位画：A(60,60) B(220,60) C(220,140) D(60,140)，
   垂直平分线过 BD 中点 (140,100) 且斜率 2，交 AB 于 (120,60)（BE=100px=10 ✓）。
   画完自己用题干的条件复算一遍交点/长度/角度。
4. **不要画的东西**：不画坐标系外的装饰、不画水印、不画来源站名、不引外部图片、不用 `<script>`/`<foreignObject>`/`on*` 事件属性。
5. **文字标注用题里的字母**（A、B、C…；角用 ∠α 、∠1 也可），字号 12–14，别用花体。
6. 统计数据图（条形/扇形/折线）**数值必须与题干一致**，刻度要标出来；含「图中数据」的题，数值只能来自题干或答案页，**不许编**。

## 三、视图里怎么用

- 题库抽屉、组卷卷面、做卷界面、错题一页纸都会渲染 `fig`；渲染方式是**取回 SVG 文本后内联**，
  所以 `currentColor` 会跟着主题走，不需要额外样式。
- 列表行里只放一个「图」小标记，不铺大图，避免手机上一屏放不下。
- 打印（`print.css`）里图按黑白处理，线条靠 currentColor 变黑。

## 四、做图流程（子任务照此执行）

1. 从 `content/bank/<城市>-<年份>.json` 里挑出**题干提到图且没有 `fig`** 的题；
2. 逐题读题干 + 答案 + 解析，把图中的点、线、角度、长度按条件确定下来；
3. 写 SVG 到 `content/bank/fig/<id>.svg`，并给该题加 `fig` / `figAlt`；
4. 跑校验器（必须是 0 错误，且「缺图」计数下降）：`python tools/build-bank.py`；
5. 抽查 2–3 张，用真浏览器截图确认渲染正常（见仓库 README 的截图流程）；
6. 拿不准能不能画对的题**不要硬画**：在汇报里列出来，宁可留着缺图，也不要画一张错的图。
